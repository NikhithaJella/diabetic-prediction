## Project-specific context

This project was built as a healthcare machine learning analysis using the UCI Diabetes 130-US Hospitals dataset to predict 30-day readmission risk.

The workflow includes data cleaning, preprocessing, feature engineering, class imbalance handling, model comparison, evaluation using recall/accuracy/F1-score, and interpretation of important risk factors.
